## 1. Color Space

| 결과 | 관찰 |
|---|---|
| BGR | 원본 컬러 |
| Gray | 색상 없이도 병뚜껑 형태가 잘 보임 |
| H | 검정·회색 뚜껑이라 색상 정보 활용도가 낮음 |
| S | 무채색이라 대부분 어두움 |
| V | Gray와 비슷하게 형태가 잘 보임 |

**판단:** 병뚜껑 유무 검사는 색상보다 형태·밝기 차이가 핵심이므로 **Gray 중심**으로 진행한다.
(색상 스티커 검사라면 HSV를 다시 검토)

## 2. Brightness (dark.jpg, alpha 1.0 고정)

| beta | 결과 |
|---:|---|
| 0 | 가장 어둡다. 홈과 경계가 잘 보이지 않는다 |
| 20 | 조금 밝아지며 형태가 더 잘 보인다 |
| 50 | 병뚜껑과 주변 영역 비교가 쉬워졌다 |
| 80 | 많이 밝아져 배경·투명 병 부분의 세부정보가 약해지기 시작한다 |

**판단:** beta 20~50이 자연스럽다. 80은 과도한 밝기의 부작용을 확인하는 비교값이다.
가장 밝은 값이 아니라 **경계는 살아 있고 밝은 영역이 날아가지 않는 값**을 고른다.

## 3. Gamma (dark.jpg)

| gamma | 결과 |
|---:|---|
| 0.6 / 0.8 | 더 어두워져 검사에 불리 |
| 1.0 | 기준 (변화 없음) |
| 1.2 | 홈과 경계가 보이기 시작 |
| 1.5 | 어두운 영역이 살아나 형태가 비교적 명확 — 현재 가장 적절 |
| 2.0 | 세부는 잘 보이나 배경·밝은 영역까지 과하게 밝아짐 |

**판단:** 어두운 이미지에는 Brightness보다 Gamma 1.5가 밝은 영역을 덜 해치면서 어두운 영역을 살린다.
단 최종 선택은 Otsu 분리 결과로 확인해야 한다.

## 4. CLAHE (low_contrast.jpg, tile 8×8)

| clipLimit | 결과 |
|---:|---|
| 1.0 | 대비 개선이 약함 |
| 2.0 | 홈과 경계가 더 분명 |
| 3.0 | 형태 구분이 더 쉬움 |
| 4.0 | 가장 선명하지만 배경 Texture·Noise도 강조 |

**판단:** 가장 선명한 4.0을 바로 고르지 않는다. 2.0~3.0을 후보로 두고 Otsu 결과로 결정한다.

## 5. Filter (noise.jpg)

| Filter | 결과 |
|---|---|
| Gaussian 3×3 | 약하게 부드러워짐, 점 Noise 많이 남음 |
| Gaussian 7×7 | 더 부드럽지만 위·아래 경계가 흐려짐 |
| Median 3×3 | 튀는 점 Noise 크게 감소, 외곽 유지 — **균형 최선** |
| Median 7×7 | Noise 가장 적음, 작은 홈·경계가 부드러워짐 |
| Bilateral | 잔잔한 Noise 감소, 밝은 점 Noise는 남음 |

**판단:** 점 Noise에는 Median 계열이 유리하다. 형태 보존은 3×3, Noise 제거는 7×7.
병뚜껑 유무 검사는 세부 무늬보다 전체 영역이 중요하므로 7×7도 후보로 남긴다.
Bilateral처럼 "경계 보존" Filter도 모든 Noise를 잘 지우는 것은 아니다.

## 6. Sharpening (blur.jpg)

| 이미지 | 관찰 |
|---|---|
| reference | 원래 홈과 경계 |
| blurred | 홈과 외곽선이 흐려짐 |
| sharpened | 경계가 다시 강조되지만 원본과 같지는 않음 |

**판단:** Sharpening은 남아 있는 경계를 강조할 뿐 사라진 정보를 복구하지 않는다.
심한 초점 실패·Motion Blur는 초점·셔터속도·제품 고정 등 촬영조건을 먼저 개선한다.

## 7. Threshold / Otsu (low_contrast.jpg, BINARY_INV)

| 방식 | 결과 |
|---|---|
| T=80 | 너무 낮음 — 거의 전체가 검정 |
| T=120 | 병뚜껑 대부분이 흰색으로 비교적 잘 분리 |
| T=160 | 너무 높음 — 배경까지 흰색 |
| Otsu | 자동 선택값 **118** — 사람이 고른 120과 거의 같은 위치에서 비교적 잘 분리 |

**판단:** 같은 이미지라도 기준값에 따라 결과가 완전히 달라진다.
120을 외우는 것이 아니라 너무 낮거나 높은 값이 왜 실패하는지가 핵심이다.

## 8. 전처리 종합 비교 (`preprocess_compare.png`)

| 조합 | Otsu 값 | 결과 |
|---|---:|---|
| Original + Otsu | 118 | 전체 형태 비교적 잘 분리, 내부·아래쪽 검정 일부 남음 |
| Gaussian(5×5) + Otsu | 118 | 형태가 부드러워지나 큰 개선 없음, 세부 단순화 |
| CLAHE(2.0) + Otsu | 132 | 일부 강조되지만 불필요 영역도 증가 |

Gaussian은 Otsu 값이 118로 그대로 → 밝기 분포를 거의 바꾸지 않음. CLAHE는 132로 기준이 올라가며 분포 자체가 바뀌어 불필요 영역이 늘었다.

**판단:** 이번 low_contrast 이미지에서는 전처리를 추가해도 분리가 확실히 좋아지지 않았다.
**Original + Otsu도 충분한 후보**이며, 도움이 안 되면 전처리를 쓰지 않는 것도 올바른 결론이다.

## 9. Glare — 촬영환경 문제

| 질문 | 답 ✏️ |
|---|---|
| 기준보다 구분하기 어려워진 부분 | 강한 반사로 하얗게 보이는 병뚜껑 표면·경계 부분 |
| Otsu 분리가 어려울 가능성 | 있음 — 반사 영역이 포화되면 뚜껑과 밝은 배경이 같은 값이 되어 하나로 묶일 수 있음 |
| 먼저 바꿔 볼 것 | 조명 각도 (반사가 카메라로 직접 들어오지 않게) → 그다음 광량 |

**판단:** 정보가 남아 있으면 전처리, 포화로 정보가 사라졌으면 촬영환경 개선이 먼저다.

## Challenge

### 문제

흰 병뚜껑과 밝은 회색 배경이 모두 밝은 계열이라 밝기 차이가 작고,
외곽 경계가 약간 흐려 Otsu에서 배경이 함께 선택될 수 있다.
(전체가 어두운 이미지는 아니므로 밝게 만드는 Brightness / Gamma > 1은 후보에서 제외 — 밝은 픽셀 포화로 차이가 더 줄어듦)

### 시도한 전처리

- CLAHE — 지역 대비를 키워 뚜껑·배경 차이 확대
- Gamma < 1 — 중간 밝기(배경)를 더 많이 낮춰 밝은 뚜껑과의 간격 확대 (예: 배경 200→약 170, 뚜껑 240→약 225)
- 전처리 없음 — 비교 기준

모든 후보에 같은 Otsu(`THRESH_BINARY`, 밝은 뚜껑 → 흰색)를 적용하고
`outputs/day02/challenge/challenge_compare.png`에서 [전처리 | Otsu]를 나란히 비교했다.

### 비교한 Parameter

- CLAHE clipLimit = 1.0 / 2.0 / 3.0 (tileGridSize 8×8 고정)
- Gamma = 0.6 / 0.8

### 최종 선택

CLAHE clipLimit = 1.0 (`SELECTED = "clahe_1.0"`)

### 선택 이유

뚜껑 몸통과 아래 링이 끊기지 않은 흰색 영역으로 나오고,
링 사이 틈(검정 띠)이 가장 선명하며 점 Noise가 가장 적었다.
clipLimit 2.0도 비슷했지만 점 Noise가 생기기 시작해 더 약한 1.0을 선택했다.

### 좋아진 점

- 원본 Otsu에서 아래 링 부분에 생기던 검은 얼룩이 메워졌다 (흰색 비율 83.7% → 89.1%)
- 링 사이 틈의 경계가 선명해졌다

### 나빠진 점

- 큰 부작용은 없으나, 위쪽 밝은 배경은 여전히 뚜껑과 함께 흰색으로 선택된다

### Otsu 비교 결과

| 후보 | Otsu 값 | 흰색 비율 | 관찰 |
|---|---:|---:|---|
| 전처리 전 (original) | 109.0 | 83.7% | 뚜껑+배경 흰색, 아래 링에 검은 얼룩 |
| **전처리 후 (CLAHE 1.0)** | **105.0** | **89.1%** | 얼룩 메워짐, 링 구조 깨끗 |
| CLAHE 2.0 | 104.0 | 88.8% | 1.0과 비슷, 점 Noise 증가 |
| CLAHE 3.0 | 128.0 | 57.4% | 뚜껑 표면 Texture가 검정으로 → 몸통 깨짐 |
| Gamma 0.6 | 68.0 | 75.0% | 뚜껑 왼쪽 위가 검게 뚫림 |
| Gamma 0.8 | 89.0 | 82.8% | 원본과 거의 동일 |

흰색 비율이 오른 것은 배경이 새로 잡혀서가 아니라 링의 검은 얼룩이 메워졌기 때문이다.
모든 후보가 83~89%로 높다는 것은 흰색이 아닌 부분이 링 사이 틈·병목뿐이라는 뜻이다.

**원인:** 이 ROI의 밝기 분포가 "어두운 틈·병목" vs "밝은 뚜껑+배경" 두 그룹으로 나뉘어,
Otsu가 뚜껑과 배경을 같은 그룹으로 판단한다. 흰 제품을 밝은 배경에서 촬영한 **촬영환경 문제**에 가깝다.

### 최종 판단

- [ ] 사용
- [ ] 미사용
- [x] 3일차 추가 확인

CLAHE 1.0은 사용하되, 뚜껑과 배경의 분리는 전처리만으로 해결되지 않는다.
3일차에 Morphology·Contour로 **뚜껑이 있을 때만 생기는 링 사이 검정 띠**의 개수·위치를 측정하는 방법을 검토하고,
가능하면 어두운 배경에서 재촬영하는 방법도 고려한다.

### 잘되지 않았던 시도

| 항목 | 작성 |

| 현상 | 홈 경계는 강조되었지만 뚜껑 표면의 세로 홈 Texture까지 강하게 강조됨 |
| Otsu 결과 | Otsu 값 128로 상승, 흰색 비율 57.4%로 급감 → 뚜껑 몸통이 검정 점으로 깨짐 |
| 판단 | 과도한 대비 강조는 객체 내부를 쪼개므로 사용하지 않는다 (Gamma 0.6도 뚜껑 일부가 뚫려 미사용) |
