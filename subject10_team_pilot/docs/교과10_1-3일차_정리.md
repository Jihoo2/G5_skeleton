# 교과 10 동작감지 1~3일차 정리 — 팀 프로젝트에 어떻게 쓰는가

> 수업에서 배운 내용 중 팀 프로젝트(맨몸운동 정석 자세 판정)에 직접 쓰이는 것만 정리.
> 오른쪽 열은 이 add-on에서 반영한 위치.

## 1일차 — Pose 기본과 YOLO Pose 실행

| 배운 내용 | 핵심 | 팀 프로젝트 반영 |
|---|---|---|
| Pose Estimation | 이미지에서 사람 관절 위치(Keypoint)를 찾는 문제. 동작 판정은 그 위에 얹는 별도 단계 | YOLO는 재학습하지 않고 관절 추출기로만 사용 (`team_03`) |
| COCO 17 Keypoint | 0 nose … 5/6 어깨, 7/8 팔꿈치, 9/10 손목, 11/12 엉덩이, 13/14 무릎, 15/16 발목 | VICON 73개 뼈 → COCO 17 매핑 (`COCO_TO_VICON`), VICON에는 얼굴 관절 없음 → NaN |
| YOLO Pose vs MediaPipe | YOLO = 여러 사람·COCO 17, MediaPipe = 한 사람·33점. 수업은 `yolo11n-pose.pt` | 같은 모델 사용, 여러 사람이 잡히면 Confidence가 가장 높은 사람 1명 (`people` 열로 기록) |
| 이미지 좌표계 | 왼쪽 위가 (0,0), **y는 아래로 증가** | GLB(위가 +y)를 투영할 때 y 부호를 뒤집음 (`project_glb`) |

## 2일차 — Keypoint 품질(Confidence)

| 배운 내용 | 핵심 | 팀 프로젝트 반영 |
|---|---|---|
| Keypoint Confidence | 관절마다 0~1 신뢰도. **0.50 이상만 사용**, 0.30~0.50 WARNING, 0.30 미만 LOW | `keypoint_confidence: 0.50`, 낮은 관절이 들어간 각도는 NaN 처리 (`resolved_series`) |
| Frame 품질 | `mean_keypoint_conf`, `low_keypoint_count` 로 Frame 상태 요약 | Sequence CSV에 그대로 포함 (`team_04`) |
| 가려짐·화면 밖 | 낮은 Confidence는 "자세가 틀림"이 아니라 "관측이 안 됨" | 판정 단계에서 NG가 아니라 **CHECK**로 분리 (`team_09`) |
| 측면 촬영 | 반대쪽 팔·다리가 가려져 Confidence가 떨어짐 | 측면은 **카메라 쪽 다리·팔만** 사용 (`near_side`) |

## 3일차 — 관절각도·정규화·Frame Feature

| 배운 내용 | 핵심 | 팀 프로젝트 반영 |
|---|---|---|
| 관절각도 `calculate_angle(a,b,c)` | b를 꼭짓점으로 하는 0~180°. 길이 1e-8 미만이면 NaN | 수업 함수를 그대로 import. 팔꿈치·무릎 + 팀 추가 고관절(어깨-엉덩이-무릎) |
| 골반 중심 이동 `center_keypoints` | 두 엉덩이 중점을 원점 → 화면 위치 차이 제거 | 그대로 사용 |
| 어깨 폭 정규화 `normalize_by_shoulder_width` | 원점 이동 후 어깨 폭으로 나눔 → 카메라 거리·체격 차이 제거 | 정면·사선은 수업 방식 그대로 (`norm_scale_mode=shoulder`) |
| (팀 추가) 측면 정규화 | 측면은 어깨 폭이 0에 가까워져 나눗셈이 폭주 | 측면은 **몸통 길이(어깨중점–엉덩이중점, 90백분위)** 로 나눔 (`norm_scale_mode=torso`) |
| 좌우 반전 `flip_keypoints_horizontal` | 좌우 이름까지 바꿔야 함 | 증강(9일차)에서 사용 예정 |
| 38-D Frame Feature | 17관절 × (x,y) 34개 + 각도 4개 | 열 이름·순서를 수업과 동일하게 유지 (`feature_columns`) |

## 3일차까지로 팀 프로젝트가 할 수 있는 것 / 4일차부터 필요한 것

- 3일차까지: **한 장면(Frame)** 의 자세를 숫자로 만드는 것까지.
- 운동은 **흐름(동작)** 이므로 Frame을 시간 순으로 묶는 Sequence(4일차), 품질 검수·사람 단위 분할(5일차)이 필요.
- 그래서 add-on은 4·5일차 구조(Manifest → Sequence CSV → QA → Subject-wise Split)를 미리 맞춰 두었고,
  분류 모델(6일차 Random Forest) 대신 **정석 기준 범위 판정**을 붙였다.

## 팀 판정 방식 (정석 기준, NG 데이터 없음)

```
VICON GLB ──(촬영 각도로 투영)──▶ 정석 동작 모양(48점 곡선) + 기준값
팀 정석 영상(train) ──▶ 1회 구간 측정값 분포 ──▶ 허용 범위 = 평균 ± max(2.5·표준편차, 최소폭)
새 영상 ──▶ 1회 구간마다 측정값 ──▶ 범위 안 OK / 밖 NG(교정 메시지) / 관절 안 보임 CHECK
```

- "정석에서 벗어나면 무조건 NG" → NG 영상을 따로 모으지 않아도 된다.
- 대신 **정석 영상의 사람 수**가 범위의 질을 결정한다 (사람 5명 이상 권장, 1명 = 1 Subject).
- VICON은 교과 규칙대로 RGB와 섞지 않고 '모양(곡선)'과 비교값(bias)으로만 쓴다. VICON 수행자·투영 각도는 새 Subject가 아니다.
