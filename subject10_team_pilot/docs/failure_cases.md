# 오류 원인 추적 사례 (team05 맨몸운동 판정)

판정이 틀렸을 때는 **어느 단계에서 틀렸는지**부터 찾았습니다.
아래 순서로 하나씩 확인하고, 원인 단계만 고친 뒤 같은 데이터로 Before/After를 비교했습니다.

```
① 입력 품질 → ② Pose(Keypoint) → ③ Feature(측정값) → ④ 회차 검출 → ⑤ 판정 규칙
```

| 단계 | 확인 방법 |
|---|---|
| ① 입력 품질 | 영상 fps·길이·잘린 구간, 사람이 화면에 다 들어오는지 (`team_02`, `team_22`) |
| ② Pose | Keypoint Confidence, 검출 프레임 비율, 오버레이 영상 (`team_03`, `team_10`, `team_13`) |
| ③ Feature | 각도·깊이 곡선이 영상 속 자세와 맞는지 (`team_04`, 결과 화면 곡선) |
| ④ 회차 검출 | 회차 시작·끝 시점, 회차 길이 (`team_23` 회차 신호 그래프) |
| ⑤ 판정 규칙 | 측정값 vs 기준값, 규칙 적용 방향 (`team_09`, `team_11`) |

## 사례 1. 스쿼트 점프 착지 동작을 1회로 셈

| 항목 | 내용 |
|---|---|
| 증상 | EXT_S04 사선 스쿼트 점프에서 3·8회차가 "몸을 더 낮게" NG. 영상으로 보면 정석 동작 |
| 추적 | ① 입력 정상 → ② Keypoint 정상 → ③ 깊이 곡선 정상 → **④ 회차 길이가 0.30·0.33초**로, 정상 1회(0.47~0.77초)보다 훨씬 짧음 |
| 원인 | 점프 후 **착지하면서 무릎을 살짝 굽힌 동작**이 회차 감지 조건을 만족해서 별도 1회로 잡힘. 얕게 굽혔으니 깊이 기준에서 NG |
| 해결 | 스쿼트 점프 1회 최소 길이 `min_rep_s` 0.3 → **0.4초**. 녹화 판정(`team_09`)과 실시간 판정(`team_21`)에 똑같이 적용 |
| 결과 | 정석 오판정 **3회 → 1회**, 실시간 vs 녹화 판정 일치율 **97%** |
| 남은 정리 | 착지 동작 회차에 붙어 있던 옛 회차 라벨(S04 3·8회차) 삭제 |

**배운 점**: NG 원인이 판정 규칙이 아니라 **회차 검출**에 있었습니다. 깊이 기준을 느슨하게 바꿨다면 진짜 덜 내려간 자세까지 놓쳤을 것입니다.

## 사례 2. 사선 정석 런지가 실시간 판정에서만 NG

| 항목 | 내용 |
|---|---|
| 증상 | EXT_S08 사선 정석 런지 1회가 녹화 판정에서는 정상인데 **실시간 판정에서만 NG**로 나옴 (`--replay-all` 비교에서 "실시간에만 있는 회차") |
| 추적 | ①~③ 정상 → ④ 깊이 신호가 1회 인정선 0.80에 정확히 걸림 → 실시간은 이 동작을 1회가 아닌 **"얕은 시도"**로 분류 → **⑤ 얕은 시도 NG 규칙**이 사선에도 적용됨 |
| 원인 | 사선은 정석 깊이 범위(0.43~0.78)가 덜 내려가기(0.63~0.77)와 겹쳐서 **깊이로 판정하지 않기로 했는데**, 얕은 시도 NG는 깊이 신호를 써서 그 원칙과 어긋남 |
| 해결 | 런지 얕은 시도 NG를 **측면에서만** 적용 (`shallow_attempt_views: ["side"]`, `shallow_ng_on()`). NG 민감도 실험(`team_11`)에도 같은 규칙 적용 |
| 결과 | 실시간에만 잡히는 회차 **0개** |

**배운 점**: 규칙을 새로 추가할 때 **기존 원칙(방향별 사용 지표)과 맞는지** 확인해야 합니다. 녹화·실시간 두 경로를 같은 데이터로 비교(`--replay-all`)한 덕분에 찾을 수 있었습니다.

## 사례 3. 기준선 경계 회차 (EXT_S05 정면 스쿼트 점프)

| 항목 | 내용 |
|---|---|
| 증상 | 1·8회차 깊이가 **0.547 / 0.552**로 기준 0.55 바로 양쪽에 걸림 → 하나는 OK, 하나는 NG |
| 추적 | ①~④ 정상 → ⑤ 측정값이 경계(±2%) 안 → 숫자만으로는 판단할 수 없어 **영상을 직접 확인** |
| 사람 확인 | 다른 회차보다 엉덩이가 무릎보다 위에서 멈추고, **상체를 숙여 깊이를 보상**한 하프 스쿼트 → 두 회차 모두 **NG** (`checked_by: 김지후`, `configs/team05_rep_labels.csv`) |
| 처리 | 규칙값은 바꾸지 않음 (한 영상에 맞춰 기준을 조정하지 않기 위해). 대신 ±2% 경계 회차를 화면에 표시해서 사용자가 알 수 있게 함 |
| 결과 | 회차 단위 라벨 기준 정석 오판정 **0/50**, 틀린 자세 검출 **1/2** |

**배운 점**: 깊이 하나만으로는 **상체 숙임 보상**을 구분하지 못합니다. 개선 후보로 최저점 상체 기울기 지표를 남겨 둡니다 (규칙 동결 후 검토).
