# 정석 자세 촬영 요청서 (팀원 공유용)

## 무엇을 찍나
- **정석 자세만** 찍습니다. 일부러 틀린 자세(NG)는 찍지 않습니다.
- 동작 3개 × 사람마다 **5 Take**
  - A001 burpee / A008 squat_jump / (3번째 동작 확정 후: A006 plank kick-through 또는 lunge)
- 사람 수: **최소 5명** (train 3 · val 1 · test 1). 많을수록 허용 범위가 정확해집니다.

## 1 Take 규칙 (교과 4일차)
- `차렷(1초) → 동작 1회 → 차렷(1초)`, 5~10초.
- 여러 번 연속으로 해도 프로그램이 1회씩 잘라 판정하지만, **1 Take = 1회** 가 검수하기 쉽습니다.

## 카메라
- 각도는 자유지만 **어느 각도인지 파일명에 꼭 적기** (GLB를 같은 각도로 돌려서 비교하기 때문).
- 권장: 휴대폰 2대 동시 촬영 → `side`(몸 옆, 90°) + `front`(정면, 0°). 가능하면 `diag`(45°) 추가.
- 높이 약 1m(허리 높이), 거리 2.5~3m, **머리부터 발끝까지 전부** 화면 안. 가로 촬영, 30fps.
- 내려다보는 높은 각도는 무릎 각도가 실제보다 크게 나옵니다(파일럿에서 약 25° 차이).
- 배경에 다른 사람이 걸리지 않게. 몸에 붙는 옷 권장.

## 파일 이름
```
T05_S01_A008_T01_side.mp4
 │   │    │    │    └ 각도: front / diag / side / deg30 같은 숫자 각도
 │   │    │    └ Take 번호 T01~T05
 │   │    └ 동작 번호
 │   └ 사람 번호 S01~ (사람 1명 = 번호 1개, 영상마다 바꾸지 않기)
 └ 팀 번호
```
- 정면·측면 동시 촬영본은 사람·동작·Take 번호를 같게 하고 각도만 다르게.
- 저장 위치: `data/team_projects/team05/rgb/videos/`
