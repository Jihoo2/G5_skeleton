● 녹화 중 시작을 누르고 카메라 사용을 허용하세요.
회차판정메시지경계·주의사람 정답

· 카메라 앞에 전신이 보이게 1초 정도 서 있다가 시작하세요. 1회가 끝나고 약 0.6초 뒤 판정이 뜹니다.
· 판정이 맞는지 직접 보고 o(OK) / n(NG)를 누르면 로그에 기록되어 실시간 일치율을 낼 수 있습니다.
· 녹화하기를 켜면 판정한 화면이 임시로 녹화됩니다. 끝난 뒤 '저장'을 눌러야 녹화 목록에 남고, 저장하지 않으면 다음 실시간 판정을 시작하거나 서버를 끌 때 지워집니다. 녹화를 끄면 영상은 남기지 않고 회차별 판정·측정값만 로그(realtime_logs)에 남습니다.
· 이 PC 웹캠: 이 PC의 브라우저에서 http://localhost:8000/live 로 열어야 카메라가 허용됩니다.
· 휴대폰 IP Webcam: 휴대폰 앱 'IP Webcam' → 맨 아래 '서버 시작' → 화면에 나온 주소 뒤에 /video를 붙여 입력 (예: http://192.168.0.10:8080/video). PC와 휴대폰이 같은 와이파이여야 하고, 앱의 해상도를 640×480으로 낮추면 더 빠릅니다.
